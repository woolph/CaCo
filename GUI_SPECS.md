# Collection Management
## Tasks
- view collection (each set separately), preferably with a card view resembling collection binder (3 columns)
  - for assessing set completion (is the collection binder complete, how many cards are missing)
  - for older sets without collector number to see where each card belongs into the collection binder
  - check on location of cards
- catalog new cards entering the collection
  - bulk addition of a bunch of cards of the same set (mostly same language, condition, etc) like for a bunch of cards from booster packs of a bundle, from a prerelease or draft
  - semi-automated bulk addition of a bunch of cards from a preconstructed deck (or any other product, where the content is well-known in advance)
  - single addition of cards from different sets, languages, conditions, etc. like it is common with a newly arrived order
    of cards for deck building
- update collection
  - removing cards
  - update grading
  - updating location

# Deck Management
- view decks

  - view missing cards (=cards that are not in collection already), display costs for missing cards
- create decks
  - import decks from other sources (archidekt, moxfield) keeping link to origin
  - create deck from scratch (with the support from other sources for card suggestions)
  - card search with scryfall synthax 
  - AI assisted card search based on some more abstract search, e.g. "cards that can be cast for less mana then their mana value")
  - AI assisted card suggestions based on the cards already in the deck
- card search for deck building
